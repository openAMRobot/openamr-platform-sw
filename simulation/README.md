# simulation

Reserved directory for cross-package simulation assets: scenario worlds, design models, and experimental environments.

> **Rule:** If a file must be used by `ros2 launch`, keep it inside `openamrobot_gazebo`.
>
> **Rule:** If a file is a project-level scenario, design asset, experimental environment, or documentation/reference asset, keep it here in `simulation/`.

Currently holds only `.gitkeep` markers — assets will be added as the platform matures.
